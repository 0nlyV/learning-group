# Changelog

Notable public changes to Learning Group are recorded here. The public app and Git history begin with version 1.0.0 after private prototyping under a different app ID.

## 1.0.0 — 2026-09-10

- Introduced configurable learning journeys for articles, books, videos, podcasts, courses, study guides, and other shared resources.
- Added separate journey posts and a persistent Portal with dated active and concluded collections.
- Added moderator creation, editing, reusable templates, and reversible conclusion controls.
- Added personal progress, aggregate participation totals, configurable closing content, and a gated discussion handoff.
- Added optional resource links, accessible typography, responsive layouts, reduced-motion support, and light/dark appearances.
- Gave the Portal a distinct indigo-and-gold identity with a four-panel mark and separate active and concluded card treatments.
