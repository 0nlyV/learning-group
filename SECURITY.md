# Security policy

## Supported version

Security fixes target the newest Learning Group version. Subreddit moderators should keep their installation updated through Reddit's App Directory.

## Report a vulnerability privately

Do not open a public issue for a suspected vulnerability, exposed credential, privacy incident, or report containing user or private-community data.

Send a private Reddit message to [u/EternalZoe](https://www.reddit.com/user/EternalZoe/) with:

- A concise description of the issue and its impact.
- The affected app version and Reddit client.
- Reproduction steps or a minimal proof of concept.
- Any practical mitigation you have identified.

Do not access, alter, retain, or disclose another person's data while investigating. Reports will be acknowledged and assessed as promptly as practical. A public disclosure timeline should be agreed before publication.

For vulnerabilities in Reddit or Devvit rather than Learning Group, use Reddit's official security-reporting process.
